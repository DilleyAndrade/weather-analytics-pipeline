# Weather Analytics Pipeline

Projeto de engenharia de dados para ingestão, armazenamento, modelagem e visualização de dados meteorológicos utilizando a API pública da Open-Meteo.

## Objetivo

Construir um pipeline completo de dados, desde a coleta via API até a visualização em dashboard web.

## Arquitetura inicial

Open-Meteo API → Python Ingestion → PostgreSQL → FastAPI Backend → React Dashboard

## Tecnologias previstas

- Python
- PostgreSQL
- FastAPI
- React
- Docker
- SQLAlchemy
- Pandas
